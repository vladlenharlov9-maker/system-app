SYSTEM 3.0 — обновление PWA для iPhone

1. Распакуй архив.
2. В репозитории system-app выбери Add file → Upload files.
3. Загрузи все файлы из архива в корень репозитория и нажми Commit changes.
4. Открой приложение в Safari и обнови страницу. Если видна старая версия — закрой вкладку и открой снова.

Данные сохраняются в localStorage под ключом systemData. Не очищай данные сайта Safari, чтобы не потерять прогресс.

Добавлены круговой таймер медитации (5/10/15/20 минут), пауза/продолжение/сброс, XP за завершение, упражнения на турнике, история тренировок и характеристика Сила. Сохранение использует прежний ключ systemData.
