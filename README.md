SYSTEM 4.1 — обновление SYSTEM 4.0

ЧТО ДОБАВЛЕНО
- Редактирование ежемесячного дохода, остатка долга, обязательного платежа, накоплений и категорий расходов.
- Автоматический подсчёт месячных расходов, остатка после расходов и капитала (накопления минус долги).
- Инвестиционный портфель: акции, облигации, фонды/ETF, криптовалюта, валюта, сырьё и другие активы.
- Запись количества, цены покупки и текущей цены; расчёт вложенной суммы, текущей стоимости и результата.
- Возможность редактировать и удалять активы. Цены вводятся вручную; онлайн-котировок и торговли приложение не выполняет.

ОБНОВЛЕНИЕ
1. Скачай резервную копию в SYSTEM → Награды → Экспорт данных.
2. Распакуй архив SYSTEM_4.1.zip.
3. В GitHub system-app выбери Add file → Upload files и загрузи все файлы из архива в корень репозитория, заменив одноимённые.
4. Нажми Commit changes.
5. На iPhone полностью закрой SYSTEM и открой снова; обнови страницу.

СОВМЕСТИМОСТЬ
Сохранён ключ localStorage systemData. Старые данные SYSTEM 4.0 (включая сделки, тренировки, медитации, миссии и финансы) сохраняются. Новые инвестиции хранятся в поле investments. Не очищай данные Safari и не удаляй приложение. Перед обновлением обязательно экспортируй резервную копию.
