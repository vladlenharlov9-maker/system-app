SYSTEM 4.0 — обновление твоей SYSTEM 3.0

ВАЖНО ПЕРЕД ОБНОВЛЕНИЕМ
1. Не очищай данные сайта в Safari и не удаляй старое приложение.
2. На всякий случай открой текущую SYSTEM 3.0 и сделай скриншоты важных показателей.
3. В репозитории GitHub system-app выбери Add file → Upload files.
4. Распакуй этот архив и загрузи ВСЕ файлы из него в корень репозитория, заменив одноимённые файлы.
5. Нажми Commit changes.
6. На iPhone полностью закрой SYSTEM, затем снова открой её и обнови страницу. При необходимости подожди минуту, пока GitHub Pages обновится.

СОВМЕСТИМОСТЬ
Приложение продолжает использовать localStorage под ключом systemData. Старые поля SYSTEM 3.0 сохраняются, а новые поля добавляются отдельно. Не нажимай очистку данных Safari. В разделе «Награды» есть экспорт и импорт резервной копии JSON.

НОВОЕ В SYSTEM 4.0
- Дневник сделок: Форекс, криптовалюта, акции, фьючерсы, индексы и сырьевые товары.
- Запись актива, BUY/SELL, результата в рублях, цен входа/выхода, стратегии, даты, причин входа/выхода и заметок.
- Возможность прикрепить скриншот графика; изображение сжимается перед сохранением.
- Статистика количества сделок, доли прибыльных и суммарного результата.
- Ежедневные и недельные задания.
- Достижения и резервное копирование данных.
- Сохранены тренировки на турнике, медитация и финансовый раздел SYSTEM 3.0.

XP за сделку начисляется за сам факт ведения дневника, а не за прибыль. Это не рекомендация торговать на реальные деньги.
